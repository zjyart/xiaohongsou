# 常见问题

## 这是开源项目吗？

不是。这是闭源 App 的公开发行仓库，只展示图文、文档和版本记录。程序源码与授权服务不公开。

## 为什么 Releases 还有 Source code？

GitHub 自动为发布标签提供仓库内容归档。这里的归档只有公开图文与文档，不含 App 构建工程。安装请下载带 `arm64-invite.zip` 的附件。

## 下载以后就能使用吗？

不能。需要获批电脑与对应邀请码。下载渠道不改变设备绑定、截止时间和撤回规则。

## 复制安装包到另一台电脑能用吗？

安装包可以被复制，但复制不授予使用资格。换绑需要管理员批准；设备约束不能保证抵抗二进制修改或硬件身份伪造。

## 邀请码用在哪？

从 App 点击“验证使用资格”，在打开的专用授权网页输入。不要使用 WordPress 管理员账号，不要在 GitHub Issue 或评论中发布邀请码。

## GitHub 下载失败怎么办？

使用 [官网备用下载](https://zhaojunyu.com/apps/xiaohongsou/download/?source=site)。同版本两个渠道使用同一份安装包与 SHA-256。

## 系统提示不能打开怎么办？

当前仍是未取得 Developer ID 签名与 Apple 公证的内测包。遇到系统或浏览器安全警告，请停止安装并联系开发者；不要禁用保护或运行绕过脚本。

## 静默更新会直接关闭 App 吗？

不会。新版在后台下载，正常退出后安装，下次打开使用新版；不会强制退出正在进行的搜索，也不会重新打开你已退出的 App。更新不会延长内测期限。

## 会访问钥匙串或读取 Chrome 登录吗？

当前版不会。产品授权通过系统浏览器完成，App 会话只留在内存；App 不读取系统浏览器 Cookie。App 内的小红书账号登录与 Chrome 独立。

## 如何反馈问题？

普通界面问题可使用 Issue 模板。涉及授权、安全或隐私时，私下联系 [zjyart@gmail.com](mailto:zjyart@gmail.com)，不要公开邀请码、设备编号、令牌或登录资料。
