# 常见问题

## 小红搜能帮我做什么？

它将小红书推荐首页改成专注搜索入口，保留真实结果和笔记。小窗便于查资料，阅读时可以收起评论与推荐内容，读完有明确的结束入口。

## 支持哪些电脑？

Apple 芯片 Mac，macOS 13 或更高。暂不提供 Intel、Windows 或手机版。实际兼容性仍受系统版本和小红书页面变化影响。

## 这是小红书官方应用吗？

这是独立开发的非官方应用，与小红书没有官方隶属、合作或背书关系。结果、笔记和内容账号由小红书提供。

## 系统提示不能打开怎么办？

当前包尚无 Developer ID 签名与 Apple 公证。遇到系统或浏览器安全警告请停止并联系开发者。不要关闭安全保护或执行绕过脚本，哈希校验不能替代公证。

## GitHub 下载不了怎么办？

使用 [官网备用下载](https://zhaojunyu.com/apps/xiaohongsou/download/?source=site)。同版本安装包与 GitHub 字节一致，并提供 SHA-256。

## 会读取浏览器登录信息或钥匙串吗？

公开版不访问钥匙串，不读取系统浏览器 Cookie。App 内小红书登录与 Chrome 独立，开发者不接收小红书登录 Cookie。

## 匿名统计收集什么？

可选统计只记录 App 版本、构建、macOS 主版本和处理器架构，最多每天一次。不向开发者上传搜索词、账号、笔记或阅读时长。默认开启，可关闭；网络安全日志仍可能记录 IP。

## 小窗会多开一个网页吗？

不会。小窗与标准窗口复用当前网页，切换不重新登录。需要时可以选择置顶，默认关闭。

## 结束搜索会清除账号或历史吗？

不会。它回到专注首页并停止本次计时，不退出账号、不删除历史，也不关闭程序。暂停专注和关闭干预是另外两种动作。

## 会强制更新并打断搜索吗？

支持后台下载和验证，正常退出后安装，下次启动使用新版，不强制退出正在搜索的 App。当前版本已开放自动更新，可在设置中关闭，也可以手动检查更新或下载。

## 这是开源项目吗？为何有 Source code？

App 闭源。这个公开仓库只有图文、文档和发行记录。GitHub 自动生成的 `Source code` 归档只打包这些公开资料，不包含可编译工程；安装请下载 `arm64-public.zip` 附件。

## 怎样反馈问题？

普通界面问题通过 Issue 模板反馈。涉及安全或隐私时私下联系 [zjyart@gmail.com](mailto:zjyart@gmail.com)。公开反馈不要附登录资料、私有笔记或未经检查的截图。
