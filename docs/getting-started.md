# 开始使用

## 系统要求

Apple Silicon Mac，macOS 13 或更高版本。当前不提供 Intel 或 Windows 安装包。

## 下载

默认使用 [GitHub Releases](https://github.com/zjyart/xiaohongsou/releases/latest)。下载名字带 `arm64-invite.zip` 的文件及同名 `.sha256.txt`。GitHub 的 `Source code` 文件是本仓库图文和文档的归档，不是 App 安装包。

GitHub 无法访问时，使用 [官网备用下载](https://zhaojunyu.com/apps/xiaohongsou/download/?source=site)。两个渠道的同版本安装包内容一致。

在终端执行下面的命令，将路径换为下载的安装包路径，结果应与 `.sha256.txt` 一致：

```sh
shasum -a 256 安装包路径
```

当前内测包尚未公证。遇到系统或浏览器安全警告，请停止安装并联系开发者，不要执行绕过警告的脚本。

## 使用资格

1. 解压安装包，确认 App 版本。
2. 在 App 的“使用资格”中复制设备编号，私下交给内测提供者批准并绑定邀请码。
3. 点击“验证使用资格”，在系统浏览器输入对应邀请码。
4. 完成后返回 App；小红书账号需要单独登录。

默认第一次启用后连续 72 小时，由服务器管理截止时间。换电脑、延长时间或恢复被撤回的资格，请联系内测提供者。重新下载或重装不会重新开始三天。

## 搜索与阅读

| 动作 | 快捷键 |
| --- | --- |
| 编辑当前搜索 | `Command + L` |
| 查找页面文字 | `Command + F` |
| 后退 / 前进 | `Command + [` / `Command + ]` |
| 搜索首页 | `Command + 1` |
| 切换小窗 | `Command + Shift + M` |
| 设置 | `Command + ,` |
| 关闭当前弹层 | `Escape` |

暂停专注是临时浏览原页面；关闭干预是停用专注模式；结束本次搜索回到首页并停止计时。这些动作不会退出小红书账号或删除搜索历史。

## 更新

0.9.0 起自动检查管理员推送的新版、后台下载和校验，正常退出 App 后静默安装。下次打开使用新版，不强制中断当前搜索。旧版用户需要先手动安装一次。

自动更新仍使用官网的签名清单和校验通道，不因为下载渠道切换而降低验证。只读位置、无写入权限或系统安全限制时保留旧版，可以在“检查更新”查看状态。
