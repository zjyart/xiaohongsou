# 开始使用

## 准备一台 Mac

支持 Apple 芯片 Mac、macOS 13 或更高版本。当前不提供 Intel、Windows 或手机安装包。小红书内容仍需要网络连接。

当前为 0.14.11 公开测试版。仍未取得 Developer ID 签名和 Apple 公证，可能被系统阻止打开。遇到系统或浏览器安全警告请停止安装并联系开发者，不要关闭保护或运行绕过脚本。

## 下载与打开

1. 在 [当前 GitHub 发行页](https://github.com/zjyart/xiaohongsou/releases/tag/v0.14.11.261030) 下载 `xiaohongsou-0.14.11.261030-arm64-public.zip` 和同名 `.sha256.txt`。
2. 可用终端命令核对完整性，结果应与校验文件一致。
3. 解压后将小红搜放到自己有写入权限的应用目录。在系统允许的情况下打开。
4. 如小红书要求登录，在 App 内按原站流程完成。

```sh
shasum -a 256 安装包路径
```

哈希只校验完整性，不等于 Apple 公证或病毒检测。GitHub 的 `Source code` 归档仅含公开文档，不是 App 安装包。

GitHub 无法访问时使用 [官网备用下载](https://zhaojunyu.com/apps/xiaohongsou/download/?source=site)。同一版本两边的安装包字节及 SHA-256 相同。

## 完成一次搜索

在首页输入问题，按回车或点击搜索。排序、筛选与结果沿用小红书原站。打开笔记后，点击顶栏关键词可修改搜索；“返回搜索结果”与普通后退分开。

小窗适合查资料，标准窗口适合展开阅读。切换复用当前网页，登录、筛选和位置不重新开始。设置中可以调整阅读主题与正文字号。

读完后点击笔记底栏“结束本次搜索”，回首页并停止本次计时，不退出账号或删除历史。暂停专注用于临时浏览原页面；关闭干预则持续停用专注模式。

| 动作 | 快捷键 |
| --- | --- |
| 打开分享文字或笔记链接 | `Command + O` |
| 打开剪贴板中的分享 | `Command + Shift + V` |
| 编辑当前搜索 | `Command + L` |
| 查找页面文字 | `Command + F` |
| 后退 / 前进 | `Command + [` / `Command + ]` |
| 搜索首页 | `Command + 1` |
| 切换小窗 | `Command + Shift + M` |
| 设置 | `Command + ,` |
| 关闭当前弹层 | `Escape` |

## 设置与提醒

专注、提醒、窗口与阅读、应用与数据分组设置。三档干预可以选择，实际适用页面与评论等偏好可独立调整。阅读提醒默认关闭，不是必须步骤。

匿名安装统计默认开启，可在软件与隐私选项中关闭；关闭不影响搜索和更新。升级不强制清除原来的登录、历史和设置。

## 更新

App 支持后台检查、下载和验证，正常退出后安装，下次启动生效，不强制退出当前搜索。无写入权限、网络或签名校验失败时保留当前版本。

当前版本已开放自动更新；也可在 App 中手动检查更新。自动更新清单由官网签名，GitHub 与官网提供同一版本的安装包。
